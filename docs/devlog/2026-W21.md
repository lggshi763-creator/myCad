## 架构亮点

### CommandBus — type-erased dispatch

`Impl::HandlerEntry` 包含两个字段：
```cpp
std::shared_ptr<void> handler;   // 持有生命周期
std::function<CommandResult(const void*, const CommandContext&)> invoker;  // 类型擦除的调用
```
`registerHandler<C>` 捕获具体 `shared_ptr<ICommandHandler<C>>` 到 `invoker` 的 lambda，外部 API 仍然完全类型安全。内部用 `std::type_index(typeid(C))` 作为 key，复杂度 O(1) 平摊。

### OpenGL 4.5 DSA API

所有缓冲区和 VAO 创建都走 Direct State Access：
- `glCreateVertexArrays` / `glCreateBuffers` / `glNamedBufferStorage`（零绑定上下文切换）
- `glVertexArrayVertexBuffer` / `glVertexArrayAttribFormat` / `glVertexArrayAttribBinding` / `glEnableVertexArrayAttrib`
- `glVertexArrayElementBuffer`

诊断三角形在 `initialize()` 里创建，`meshes.empty()` 时自动渲染，方便在真实几何接入前验证渲染管线。

### CreateBoxCommandHandler + renderer（可选注入）

第 4 参数 `shared_ptr<IRenderPort> renderer = nullptr` 默认为空，存量测试零改动。renderer 非空时，handler 在 `appendOne` 后调用 `tessellate(handle, tessParams)` → `uploadMesh(handle, mesh)`。网格上传失败为非致命：事件已持久化，命令仍返回成功。

### Camera — 球坐标 + Eigen

```
eye = target + radius * {cosEl·sin(Az), sin(El), cosEl·cos(Az)}
```
`viewMatrix()` 手写 lookAt（右手系，Y-up）；`projMatrix(aspect)` 手写标准透视矩阵。`Eigen::Matrix4f::data()` 直接传给 `glUniformMatrix4fv(... GL_FALSE ...)`，无拷贝。

### glReady 信号 + onGlReady 槽

`QOpenGLWidget::initializeGL()` 是第一个在活跃 GL context 内的回调。`ViewportWidget::initializeGL` 末尾 `emit glReady()`，`MainWindow::onGlReady` 发出 demo `CreateBoxCommand{2, 3, 4}`，handler 内完成 makeBox → tessellate → uploadMesh，随后 `viewport_->update()` 触发首帧渲染。整个流程无 Qt event loop 之外的时序假设。

## 卡点记录

| 卡点 | 根因 | 解决 |
|---|---|---|
| MSVC 19.50 "No known features" | CMake 4.3 feature table 未收录 MSVC 19.50；EnTT 导出 `cxx_std_17` 传递依赖触发查表 | 手动 seed `CMAKE_CXX_COMPILE_FEATURES`，全局 `CMAKE_CXX_STANDARD 23` 代替 per-target |
| `-Wshadow` on value object constructors | GCC/Clang with `-Werror`，参数名与成员名同名 | 统一改参数名加 `_` 后缀（`x_`、`origin_`、`min_` 等） |
| `<expected>` not found (ubuntu-22.04) | GCC 11 无 `std::expected` | CI runner 升级为 ubuntu-24.04（GCC 13） |
| `uploadMesh` 在 GL context 未就绪时被调用 | main.cpp 直接 `bus->send` 时窗口尚未 `show()` | 改为 `glReady` 信号延迟到 `initializeGL` 后执行 |
